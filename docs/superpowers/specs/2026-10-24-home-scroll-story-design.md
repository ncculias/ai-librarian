## 1. 意圖

現在的首頁只有一句英文標語和一顆 Start，看不出這個網站是什麼、能做什麼。參考 mydopo.com 這類
「產品釘在畫面中間、說明隨捲動一段段出現、超大字當背景」的產品頁手法，把首頁做成四段可捲動的敘事：
一眼看懂這是 AI 館員、三個功能各做什麼、繪本是怎麼來的，最後給三個清楚的入口。

## 2. 目標 / 非目標

目標
- 四段式首頁，網址仍是 `/`：大字開場 → 顏如玉釘住介紹三個功能 → 照片變故事書 → 索引式入口。
- 三個入口對應頁首三個分頁：聊天問答 `/librarian`、書籍介紹 `/book-guide`、繪本生成 `/my-story-book`。
- 顏如玉用**靜態圖**（不載 Live2D，首頁要快），只在第二段出現；第一段不放人物。
- 深色／淺色、手機單欄、A+/A-、鍵盤操作、`prefers-reduced-motion` 都要可用。
- 不加 npm 依賴：捲動效果用原生 scroll 事件 + IntersectionObserver + CSS。
- 圖檔缺失（正式機未 rsync）時版面照常，只是第二段沒有人物。

非目標
- 不做 Live2D 首頁（之後可把第二段的靜態圖換成 Live2D 區塊，版面不變）。
- 不做逐格圖片序列（mydopo 的產品轉動）。
- 不改其他頁面；Navbar 只加「首頁也顯示」這一件事。
- 不做多語切換。

## 4. 版面與動態

共通
- 字體：標題用襯線「Noto Serif TC」（Google Fonts，`display=swap`，載不到就退回系統襯線），內文維持現有黑體。
- 配色沿用 `index.css` 的 theme 變數（`--color-accent-strong` 等），不新增色票；黃色標籤用 `#facc15`／深色字。
- 頁首：首頁也顯示現有 `Navbar`（`App.tsx` 拿掉 `!isHome` 條件）；Hero 高度 `calc(100vh - 3.5rem)`。
- 背景：保留首頁現有的流動光暈與漂浮小點（`.home-shell` 背景），加一層很淡的噪點（SVG data URI）。
- 所有說明文字用 `msg-text` / `msg-text-sm`（跟著 A+/A-）；大字用 `clamp()` 隨視窗縮放。
- `prefers-reduced-motion: reduce`：關閉所有 animation/transition，捲動步驟仍可切換（直接跳狀態）。

第一段：三行大字依序從左滑入（0.1s / 0.35s / 0.6s）；中央一圈淡藍光暈緩慢脈動；往下捲時大字淡出並上移
（opacity = 1 − 1.2·p，translateY = −60px·p，p = scrollY / 視窗高）。

第二段：外層高 320vh，內層 `position: sticky; top: 3.5rem; height: calc(100vh - 3.5rem)`。
進度 p = −top / (高 − 視窗高)，步驟 step = p<0.12→0，<0.42→1，<0.72→2，否則 3。
step ≥ n 時第 n 個標註淡入上移；人物依 step 平移：`0 / +14vw / −14vw / +12vw`（0.6s 緩動）。
手機（<768px）：不釘住，改成一般流：人物（高 46vh）在上、三個標註上下排，進入視窗才浮現。

第三段：大字在最前（z-index 3），拍立得在後（z-index 1、opacity .38、深色 .28），進入視窗時從下方浮上並帶旋轉
（−6° / 3° / −2°，延遲 0 / .15s / .3s）。

第四段：三行依序浮現（延遲 0 / .1s / .2s）；hover：整行淡藍漸層從左展開、標題右移 14px、箭頭變藍並旋轉 −45°、
中間浮出一張斜的小色塊預覽（手機不顯示）。每一行是 `<Link>`，可 Tab / Enter。
